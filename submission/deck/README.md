# Svinkki pitch decks

- [`Svinkki-deck.pdf`](Svinkki-deck.pdf) (from `index.html`): 8 slides, about 3 to 4 minutes.
- [`Svinkki-60s.pdf`](Svinkki-60s.pdf) (from `lightning.html`): 5 slides, about 90 seconds.

GitHub shows the PDFs in the browser. To present, download the folder and open the HTML in any
browser: arrow keys, space or click to move; F for full screen; `#4` in the address jumps to slide 4.
No internet needed. Screenshots in `img/` are the real app on synthetic data.

Re-export a PDF: open the HTML in Chrome, Print, "Save as PDF", margins None, background graphics on.
