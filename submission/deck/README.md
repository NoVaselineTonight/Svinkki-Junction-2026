# Svinkki pitch decks

- `index.html` / `Svinkki-deck.pdf`: 6 slides, about 3 minutes.
- `lightning.html` / `Svinkki-60s.pdf`: 3 slides, about 60 seconds.

Open the HTML in any browser. Arrow keys, space or click to move; F for full screen; `#3` in the
address jumps to slide 3. No internet needed. Screenshots in `img/` are the real app on synthetic data.
Re-export a PDF: open the HTML in Chrome, Print, "Save as PDF", margins None, background graphics on.
